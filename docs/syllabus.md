# Java Full Stack Developer — Complete Syllabus

## How to Use This Syllabus

- REVISE: I have studied this before.
- LEARN: I need to study this properly.
- TEST: I should answer questions or write code without notes.
- BUILD: I should create a project using these skills.

## Study Rule

1. Test topics you already know.
2. Revise topics you partly remember.
3. Learn topics you cannot explain or implement.
4. Build projects before completing every advanced topic.
5. Start applying for fresher jobs when you have a solid project and can explain your code.
